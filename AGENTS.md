## Agent skills

### Issue tracker

Issues live in Jira project SCRUM (asdevwishes.atlassian.net, team-managed board 1) via the `jira` MCP tools, not GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default labels: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
