# Use Apache License 2.0 for the project

ThalassaOps will be released under Apache License 2.0. This provides a permissive license suitable for an infrastructure product, gives community and enterprise users broad reuse rights, includes an explicit patent grant, and keeps the core product, Rust crates, React packages and connector SDK straightforward to adopt. Huawei Cloud is deferred from the current scope and is not included in the current integration baseline.
